# FLAVOR MATRIX 3D

3D-граф сочетаемости ингредиентов, симулятор раскрытия вкуса (Sip Evolution) и подборщик коктейлей.
React + TypeScript + Vite + Tailwind CSS + чистый Three.js. Работает полностью локально, без API-ключей.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # сборка в dist/
npm run build:single # всё приложение одним файлом dist-single/index.html
npm run typecheck    # проверка TypeScript
```

Нужен Node.js 20.19+ (или 22.12+).

## «Мой бар» и режим 0%

- **Мой бар** (вкладка в «Подборе»): отметьте, что есть дома, — приложение покажет, что можно приготовить сейчас,
  чего не хватает одного ингредиента и минимальный список покупок, чтобы открыть ещё ~5 коктейлей. Отметки хранятся в браузере.
- **0%** (кнопка в шапке): все рецепты показываются в безалкогольной версии с заменами (`src/utils/nonAlcoholic.ts`),
  алкогольные узлы в 3D гаснут, а при добавлении алкоголя в шейкер он сразу меняется на безалкогольную альтернативу.
  В конструкторе есть кнопка «Сделать безалкогольным». Биттеры в этом режиме убираются — в них 45% алкоголя.

## ИИ для нестандартных запросов

Приложение само выбирает, чем разбирать запросы вроде «как закат в Барселоне»:

1. **Артефакт на claude.ai** — встроенный Claude, ключ не нужен (тратится лимит зрителя).
2. **Полная версия на Vercel** — серверная функция `api/ai.ts` с вашим ключом. Пользователям ничего вводить не надо.
3. **Личный ключ** — кнопка «ИИ» в шапке (OpenAI или Gemini), хранится в браузере.
4. **Ничего из этого** — работает встроенный словарь синонимов.

### Как выложить полную версию с ИИ для всех (Vercel, бесплатный план)

1. Загрузите папку проекта на GitHub (без `node_modules`).
2. На vercel.com → **Add New → Project** → выберите репозиторий. Vercel сам поймёт, что это Vite.
3. В **Settings → Environment Variables** добавьте `GEMINI_API_KEY` (ключ с aistudio.google.com) **или** `OPENAI_API_KEY`.
   Необязательно: `AI_MODEL` — название модели.
4. Нажмите **Deploy** (или **Redeploy**, если добавили ключ после первого деплоя).

Проверка: откройте `https://ваш-сайт.vercel.app/api/ai` — должно быть `{"configured":true}`, а в шапке приложения — «ИИ · сервер».

Защита: функция принимает только описание вкуса до 300 символов, сама собирает промпт про коктейли
и пускает не больше 10 запросов в минуту с одного IP. Запросы оплачиваются с вашего ключа — поставьте лимит
расходов в кабинете OpenAI / Google.

Локально с сервером: `npm i -g vercel`, затем `vercel dev` (ключ — в файле `.env.local`, его нельзя загружать на GitHub).

## Структура

```
api/
  ai.ts                        — серверная функция Vercel: ключ ИИ хранится на сервере
src/
  App.tsx                      — шапка, переключатель режимов, общее состояние
  components/
    Scene3D.tsx                — Three.js: узлы, связи, пыль, Raycaster, OrbitControls, dispose
    TastingTimeline.tsx        — ползунок 0–45 сек, Play/Pause, строка «что чувствуется сейчас»
    NodeInspector.tsx          — карточка выбранного ингредиента и его лучшие пары
    CocktailBuilder.tsx        — конструктор: слайдеры, техкарта, ABV, баланс, сохранение, экспорт
    DiscoveryPanel.tsx         — подбор: по коктейлю / по ингредиентам / по настроению
    MyBarPanel.tsx             — вкладка «Мой бар»
    CocktailCards.tsx          — карточки коктейлей
    SettingsModal.tsx          — необязательный ключ OpenAI / Gemini
    ui.tsx                     — мелкие общие элементы
  data/
    types.ts                   — типы
    ingredients.ts             — 46 ингредиентов + 6 безалкогольных, 6 категорий, связи
    cocktails.ts               — 45 коктейлей (18 обязательных + твисты)
  utils/
    mixologyMath.ts            — объём, обводнение льдом, ABV, метод, бокал, баланс, таймлайн
    recommendationEngine.ts    — похожие коктейли, «люблю/не переношу», разбор текста, авторская связка
    storage.ts                 — localStorage (сохранённые рецепты, настройки ИИ)
    claudeBridge.ts            — встроенный Claude и сохранение файлов на claude.ai
    nonAlcoholic.ts            — замены для режима 0% и безалкогольные версии коктейлей
    myBar.ts                   — «Мой бар»: что готово, чего не хватает, план покупок
```

## Как считается крепость

Обводнение льдом — по формулам Дэйва Арнолда (x — крепость смеси до льда, в долях):

- Stir: `D = −1.21·x² + 1.246·x + 0.145`
- Shake: `D = 1.567·x² + 1.742·x + 0.203`
- Build: `D ≈ 0.10`

Итоговая крепость = мл чистого спирта / (объём × (1 + D)).

## Управление

- Клик по сфере — связи и % синергии, остальное тускнеет.
- Двойной клик или кнопка «В шейкер» — добавить ингредиент.
- Пробел — запустить / остановить глоток, Esc — снять выделение.
